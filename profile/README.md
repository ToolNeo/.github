# ToolNeo

这里有两个在线工具：面向开发与日常办公的**在线工具箱**，以及用于活动礼金登记和大屏展示的**在线礼簿**。

| 工具 | 在线地址 | 主要用途 |
| --- | --- | --- |
| 在线工具箱 | [tool.vyide.com](https://tool.vyide.com/) | 数据转换、开发辅助、信息查询、图片与文件处理 |
| 在线礼簿 | [gift.vyide.com](https://gift.vyide.com/) | 活动管理、礼金登记、统计导出、独立礼簿展示 |

## 在线工具箱

[打开在线工具箱 →](https://tool.vyide.com/)

把常用的小工具集中到浏览器里。可以按分类浏览，也可以搜索工具名称或用途，收藏常用工具，并查看最近使用的工具。

| 功能方向 | 代表功能 |

| JSON 与数据处理 | 格式化、校验、树形查看、查询、对比、合并与 Schema 校验；JSON、CSV、YAML、XML、TOML 转换，以及代码模型生成 |
| 代码格式化与 Markdown | JavaScript、TypeScript、HTML、CSS、SQL 等代码格式化；Markdown 编辑预览、HTML 互转、表格与目录生成 |
| 文本整理与生成 | 字数统计、去重排序、文本对比、命名转换、Unicode 与转义处理；密码、随机数、Token、二维码和条形码生成 |
| 开发辅助 | Base64、URL 编解码、UUID、哈希与 HMAC、JWT 解析、正则测试、Cron 表达式、颜色转换、HTTP 请求代码生成 |
| 网络与网站 | IP、DNS、域名注册、HTTPS 证书、网站状态与响应头、SEO 元数据、robots 与 Sitemap、RSS / Atom、城市天气查询 |
| 地图与地理 | 坐标拾取、地址与经纬度互查、坐标系转换、距离与面积测量、路线规划 |
| 图片、PDF 与文件 | 图片压缩、格式转换、裁剪、水印、取色与 EXIF 查看；PDF 合并、拆分、旋转、页面整理及文本或图片提取；文件哈希与 ZIP 目录检查 |
| 单位与进制 | 长度、面积、质量、体积、温度、速度等单位换算，以及多种进制与十六进制文本转换 |

### 还能查询哪些信息

- **软件包与版本**：查询 npm、Maven、PyPI、NuGet、Go Module 等软件包信息；各工具按支持范围展示版本、依赖、许可证或发布历史。
- **开源项目与漏洞**：查看 GitHub / GitLab 公开项目及发行版本，查询 GitHub 提交和工作流，以及 CVE 与依赖已知漏洞信息。
- **网络与站点**：公网 IP、域名与 DNS、证书、网站响应头、SEO 信息和订阅源条目。
- **日常参考信息**：天气预报、节假日与调休、参考汇率、地图与地理位置。

查询类工具需要联网，部分功能依赖后端或第三方数据服务；具体处理方式以各工具页面说明为准。

## 在线礼簿

[打开在线礼簿 →](https://gift.vyide.com/)

适合婚丧喜庆、亲友往来等场景的礼金登记。**管理端负责录入和整理，展示端通过独立只读链接打开**，可以在另一台电脑、电视或大屏上展示礼簿。

### 适用活动

结婚、订婚宴、大寿、满月酒、百天酒、周岁宴、乔迁宴、升学宴、开业庆典、丧事。

### 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| 活动管理 | 新建和编辑活动，选择活动类型，填写时间与描述；结束或重新开启活动，删除已结束的活动 |
| 礼金登记 | 记录姓名、礼金、现金或微信、到场人数及备注，支持连续录入；同名信息在当前活动内提醒 |
| 更正与操作记录 | 更正或作废礼金记录，查看操作记录及操作者姓名 |
| 明细与统计 | 筛选礼金明细，查看有效礼金总额、登记笔数、到场人数和支付方式汇总 |
| Excel 导出 | 按当前活动和筛选条件导出礼金明细，下载真正的 `.xlsx` 文件 |
| 展示设置 | 配置展示标题、活动照片和每页列数，预览样式，生成可以反复打开的只读展示链接 |
| 独立礼簿展示 | 根据活动类型应用不同主题，展示活动信息、照片、手写风格姓名和金额；支持分页、全屏及录入后自动更新 |
| 备份与恢复 | 下载活动数据备份，并将备份恢复为新活动 |
| 账号与权限 | 邮箱验证码注册、邮箱验证修改密码；普通用户按权限管理自己创建的活动和礼金数据 |

现金和微信是**人工登记的支付方式**。到场人数单独填写，可以记录一户实际来了几个人。

### 怎么使用

1. 注册并登录，创建活动，选择活动类型并填写时间与描述。
2. 在展示设置中填写标题、上传照片，生成展示链接，在另一台设备或独立窗口打开。
3. 管理端录入礼金，展示端自动更新；按需要查看统计、更正记录或翻页展示。
4. 活动结束后，导出 Excel 明细或下载活动备份。
